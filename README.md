# Pluschat для Android

Нативный Android-клиент Pluschat на Java. Интерфейс развивается в соответствии с макетом Figma:

https://www.figma.com/design/K1DkOFipvcBO19qrmWnZGG

## API

Приложение обращается к выделенному протокольному шлюзу по HTTPS:

`https://xn--n1aabel.xn--80avljg2a1c.xn--p1ai/api/v1/`

Клиент не должен обращаться напрямую к основной БД или хранить в APK пароли БД, приватные ключи сервера либо секреты межсерверного соединения.

## Сборка APK

GitHub Actions автоматически собирает debug APK при push в `main`, при pull request и вручную через вкладку Actions. Сборка запускает `assembleDebug` и `lintDebug`; APK публикуется как артефакт `pluschat-debug-apk` на 14 дней.

Локально: открой проект в Android Studio и выбери **Build → Build APK(s)**. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Важно

- Успешная компиляция не доказывает доступность сервера или работу всех API-операций.
- Реальная регистрация, подтверждение email и сообщения требуют развернутого PHP API и корректной конфигурации хостинга.
- Наличие HTTPS и шифрования токена на устройстве не означает, что сквозное шифрование сообщений (E2EE) уже реализовано.
