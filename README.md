# Pluschat для Android

Нативный Android-клиент Pluschat на Java. Интерфейс развивается в соответствии с макетом Figma:

https://www.figma.com/design/K1DkOFipvcBO19qrmWnZGG

## Единый сервер и API

Приложение напрямую обращается к основному PHP API по HTTPS:

`https://xn--80avljg2a1c.xn--p1ai/api/v1/`

Для текущей архитектуры не требуется отдельный обязательный протокольный шлюз. Хост `xn--n1aabel.xn--80avljg2a1c.xn--p1ai` не является обязательным промежуточным сервером клиента.

Клиент не должен обращаться напрямую к MySQL или хранить в APK пароли БД, SMS/API-ключи, приватные серверные ключи либо секреты.

## Сборка APK

GitHub Actions собирает debug APK при push в `main` и вручную через вкладку Actions. Workflow запускает `assembleDebug` и `lintDebug`; APK публикуется как артефакт `pluschat-debug-apk` на 14 дней.

Локально: открой проект в Android Studio и выбери **Build → Build APK(s)**. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Важно

- Успешная компиляция не доказывает доступность сервера или работу всех API-операций.
- Реальная регистрация, подтверждение SMS/email и сообщения требуют работающего PHP API и корректной конфигурации хостинга.
- SMS требует серверной настройки TextBee: `PLUSCHAT_TEXTBEE_API_KEY` и `PLUSCHAT_TEXTBEE_DEVICE_ID`. Секретный ключ нельзя хранить в репозитории или APK.
- Звонки ещё требуют интеграции с Android-клиентом и работающего WebRTC/signaling. Наличие экрана звонков само по себе не означает, что звонки работают.
- Наличие HTTPS и клиентского шифрования токена не доказывает, что сквозное шифрование (E2EE) реализовано для каждой функции.
