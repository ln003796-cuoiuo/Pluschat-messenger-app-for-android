# Плюс Чат — Flutter Android

Flutter-приложение мессенджера с прямым HTTPS-подключением к основному PHP API.

## Принципы
- Никакого шлюза/прокси.
- Не хранить секреты сервера и TextBee в приложении.
- Токен сессии хранить в Android secure storage.
- Не показывать фиктивные сообщения как реальные данные сервера.
- Сообщения принимаются/отправляются в формате `pc-e2ee-v1`; реальное E2EE требует отдельной проверенной реализации обмена ключами и криптографии на устройствах.

## Сборка локально
Установить Flutter SDK и Android SDK, затем:
```sh
flutter pub get
flutter analyze
flutter build apk --release
```

GitHub Actions не требуется. Сборка APK выполняется локально.

## API
Базовый адрес задан в `lib/core/api_client.dart`. По умолчанию используется основной домен Pluschat, без промежуточного шлюза.

## Статус
Это начало новой Flutter-кодовой базы. Серверные функции подключаются по реальным API-контрактам; наличие файла на сервере не означает, что функция уже проверена на рабочем хостинге.
